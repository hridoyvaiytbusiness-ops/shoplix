# SHOPLIX ই-কমার্স ও রিসেলার প্ল্যাটফর্ম

SHOPLIX হলো একটি পূর্ণাঙ্গ আধুনিক ই-কমার্স, রিসেলিং ও ড্রপশিপিং প্ল্যাটফর্ম যা React 19, TypeScript, Tailwind CSS এবং Firebase দিয়ে তৈরি।

---

## 🤖 অন্য Google AI Studio-তে ওপেন করার নিয়ম
1. এই প্রজেক্টের সমস্ত ফাইল আপনার **GitHub** একাউন্টে একটি নতুন রিপোজিটরিতে আপলোড (Push) করুন।
2. অন্য **Google AI Studio**-তে যান এবং **"Import from GitHub"** বাটনে ক্লিক করে রিপোজিটরি লিংক দিন।
3. Google AI Studio সাথে সাথে এই প্রজেক্টের ডিপেন্ডেন্সি ইনস্টল করে লাইভ প্রিভিউ চালু করে দেবে!

## 💻 নিজের কম্পিউটারে (Windows / Mac / Linux) চালানোর নিয়ম

### উপায় ১ (সবচেয়ে সহজ - এক ক্লিকে):
- নিশ্চিত করুন আপনার কম্পিউটারে [Node.js](https://nodejs.org/) ইনস্টল আছে।
- Windows-এ: ফোল্ডারে থাকা **`RUN_PROJECT_WINDOWS.bat`** ফাইলে ডাবল ক্লিক করুন! এটি স্বয়ংক্রিয়ভাবে প্যাকেজ ইনস্টল করে ব্রাউজারে `http://localhost:3000` ওপেন করবে।
- Mac / Linux-এ: টার্মিনালে `bash RUN_PROJECT_MAC_LINUX.sh` রান করুন।

### উপায় ২ (টার্মিনাল দিয়ে):
```bash
# ১. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` ওপেন করুন।
