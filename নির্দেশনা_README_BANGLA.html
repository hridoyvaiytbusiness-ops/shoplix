SHOPLIX E-COMMERCE

ওয়েবসাইটটি আনজিপ (Unzip) করার পর ব্যবহারের সহজ নিয়ম

SHOPLIX একটি পূর্ণাঙ্গ React 19 + TypeScript + Tailwind CSS প্ল্যাটফর্ম। ফাইলগুলো আনজিপ করার পর আপনি যেভাবে এটি চালাতে পারবেন:

🤖 পদ্ধতি ১: অন্য Google AI Studio-তে ওপেন করার নিয়ম

  1. এই সম্পূর্ণ ফোল্ডারটি আপনার GitHub একাউন্টে আপলোড (Push) করুন।
  2. অন্য Google AI Studio Build-এ গিয়ে হোম পেজে "Import from GitHub" অপশনটিতে ক্লিক করুন।
  3. আপনার GitHub রিপোজিটরির লিংকটি পেস্ট করে Enter চাপুন।
  4. Google AI Studio স্বয়ংক্রিয়ভাবে সমস্ত প্যাকেজ ইনস্টল করে ওয়েবসাইটটি সাথে সাথে লাইভ রান করবে!

💻 পদ্ধতি ২: নিজের কম্পিউটারে (Windows / Mac) এক ক্লিকে চালানো

  1. নিশ্চিত করুন আপনার পিসিতে Node.js ইনস্টল আছে (না থাকলে nodejs.org থেকে ডাউনলোড করে নিন)।
  2. Windows ব্যবহারকারীদের জন্য: ফোল্ডারে থাকা RUN_PROJECT_WINDOWS.bat ফাইলটিতে ডাবল ক্লিক করুন!
  3. Mac / Linux ব্যবহারকারীদের জন্য: টার্মিনালে bash RUN_PROJECT_MAC_LINUX.sh রান করুন।
  4. ওয়েবসাইটটি স্বয়ংক্রিয়ভাবে চালু হয়ে আপনার ব্রাউজারে http://localhost:3000 ওপেন হবে!

⚡ পদ্ধতি ৩: ম্যানুয়ালি টার্মিনালে চালানো

টার্মিনাল বা কমান্ড প্রম্পটে ফোল্ডারটি ওপেন করে নিচের দুটি কমান্ড রান করুন:

npm install
npm run dev

এরপর ব্রাউজারে ওপেন করুন: http://localhost:3000
