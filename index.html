🛍️ SHOPLIX ই-কমার্স ও ড্রপশিপিং প্ল্যাটফর্ম

ওয়েবসাইটটি সরাসরি ফাইল ব্রাউজারে ওপেন করা হয়েছে

যেহেতু এটি React 19 ও TypeScript দিয়ে তৈরি একটি আধুনিক ডাইনামিক ওয়েব অ্যাপ্লিকেশন, তাই সাধারণ ব্রাউজারে ডাবল ক্লিক করে file:// প্রোটোকলে চালালে ব্রাউজার মডিউল লোড করতে পারে না।

🚀 সহজেই এক ক্লিকে চালানোর উপায়:

  1. ফোল্ডারে থাকা RUN_PROJECT_WINDOWS.bat ফাইলে ডাবল ক্লিক করুন।
  2. অথবা টার্মিনাল/কমান্ড প্রম্পটে রান করুন: 
    npm install
npm run dev
  3. এরপর ব্রাউজারে http://localhost:3000 ওপেন করুন।

🤖 অন্য Google AI Studio-তে চালানোর নিয়ম:

১. এই পুরো ফোল্ডারটি আপনার GitHub একাউন্টে আপলোড (Push) করুন।
২. অন্য Google AI Studio-তে গিয়ে "Import from GitHub" অপশনে আপনার GitHub লিংক দিন—পুরো ওয়েবসাইটটি সাথে সাথে লাইভ হয়ে যাবে!

💡 বিস্তারিত নির্দেশনার জন্য ফোল্ডারে থাকা নির্দেশনা_README_BANGLA.html ফাইলটি ওপেন করুন।
